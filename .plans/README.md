# Local Plan Split Tracker

This directory is intentionally gitignored except for this file and `.gitkeep`.

Use it to stage local notes while splitting `PLANNING.md` into one branch and PR per plan item.

## Branch and PR mapping

1. `feat/mcp-endpoint-v0.2` - plan 1 (MCP endpoint)
2. `feat/replay-fixtures-v0.2` - plan 2 (record and export replay fixtures)
3. `feat/ai-explain-pane-v0.2` - plan 3 (AI explain pane)
4. `docs/llms-manifest-v0.2` - plan 4 (`llms.txt` and API manifest)
5. `chore/release-automation-v0.2` - plan 5 (semantic release flow)
6. `chore/repo-metadata-v0.2` - plan 6 (repository, bugs, homepage fields)
7. `feat/ai-explain-route-v0.2` - plan 7 (`/ai-explain` route)
8. `chore/upstream-sync-policy-v0.2` - plan 8 (upstream sync policy)

## Local-only plan files

Create local files here as needed, for example:

- `.plans/1-mcp-endpoint.md`
- `.plans/2-replay-fixtures.md`
- `.plans/3-ai-explain-pane.md`

Those local plan files stay untracked by default.
